### 🧠 About Me

I'm an **AI Engineer & Full Stack Developer** who builds intelligent systems end-to-end — from fine-tuning LLMs to shipping production-ready web apps. I care about the full picture: clean architecture, robust ML pipelines, and deployment that doesn't break at 3am.

- 🤖 **Obsessing over:** LLMs, RAG pipelines, and getting generative AI into real products
- 🏗️ **Full Stack core:** Spring Boot microservices on the backend, React on the front
- ☁️ **DevOps layer:** CI/CD pipelines, Docker, and Google Cloud for deploying ML at scale
- 🎯 **Philosophy:** Train it. Ship it. Monitor it. Iterate.
